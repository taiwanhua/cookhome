# 表單管理

## 這個模組做什麼

設計各模組要填寫的**表單**:欄位、版面、版本,以及表單在你的組織裡開不開放填寫。畫面左側是表單清單,右側是選中表單的「表單設計」與「表單版本」兩個頁籤。

表單分兩種:

- **共用表單**:由系統管理員建立並提供給你的組織。你可以看、可以開關,但不能直接改它的欄位。
- **自己的表單**:以某張共用表單的某一版為基底建出來、只有你的組織看得到。欄位、版本都由你管理。

## 常用操作

- **以此為基底建新表單**:在右側標頭按這個按鈕,選一個基底版本,填**表單 key** 與名稱。表單 key **建立後不能修改**(只能用小寫英文開頭、小寫英文 / 數字 / 底線)。建好後會帶著一份草稿,可以直接開始改。
- **表單設計**:
  - 從「元件」面板把欄位型別拖到畫布上(或直接點一下加在最後),畫布上的欄位可以拖拉調整順序與分區。
  - 點選畫布上的欄位,在右側的屬性面板改顯示名稱、元件、寬度、必填、選項、公式、顯示條件、鎖定條件等;每種欄位只會出現它用得到的設定(例如上傳與引用欄位沒有「值的來源」)。
  - 改**欄位 key** 時,格式不對或和別的欄位重複會立刻標紅,不會寫進去。
  - 公式與條件用選單組出來,不用自己打字;每一格只列型別對得上的欄位、系統值(現在時間、時區、填寫者、填寫者的組織)、常數與運算。條件一定要組成「是 / 否」的判斷,不能只放一個常數。下方的「JSON 預覽」可以複製。
  - **鎖定條件(成立時此欄位不可修改)**:條件成立時這一欄變成唯讀。**自訂驗證(條件成立才通過)**:條件不成立就擋下送出,並顯示你填的**錯誤訊息**。
  - 選項來源的類別、來源表單與它的欄位都從下拉挑:來源表單只列看得到且已經發布過的。
  - 計算與固定值欄位在畫布與填寫頁顯示成唯讀的框,不能直接改。
  - 沒有選欄位時,右側是「表單設定」:指定摘要的**標題**(必填)、日期、金額,以及帶入資料的規則。
  - 帶入規則照填寫時的順序設定:**規則名稱**(填寫時「帶入資料」跳窗的來源清單顯示它)→ 來源(使用者 / 組織 / 表單提交)→ 表單 → 顯示欄 → 固定條件(選填)→ **對應表**(每一列「本表單欄位 ← 來源欄位」,來源欄位只列型別合得上的)。
  - 「檢查結果」列出目前的錯誤與警告,點一下會帶你到出問題的欄位。有錯誤不能發布,警告可以。
  - 按「預覽」切換成填寫的樣子,輸入測試值看條件與公式的結果(不會建立任何資料)。
  - 改完按「存草稿」。
- **表單版本**:
  - 草稿那一列按「發布」,填**變更說明**(必填)後送出;發布後所有人新增時都用這一版。
  - 顯示「發布中斷」時按「重試發布」,會從中斷的地方接著完成。
  - 「退役目前版本」:之後這張表單不能再新增,直到再發布一個新版本;既有資料照常可以看。
  - 任何一個版本都可以「以此版本為基底開新草稿」(已經有草稿時要先處理掉那份草稿),也可以看它「與上一版差異」。
- **編輯名稱與標題**:頁籤 / 標題模板只能引用摘要(`{{title}}`、`{{date}}`、`{{amount}}`),下方會即時顯示用範例資料套出來的樣子。
- **在本組織啟用**:右側標頭的開關決定這張表單在你的組織開不開放新增;關掉只擋新增,不影響既有資料。
- **流程綁定**:右側標頭下的「送出後走的審核流程」決定這張表單送出後要不要審核、走哪個流程(流程在「流程管理」設計)。
  - 下拉只列**可以直接綁**的流程;選「不走流程」就是送出即完成。一張表單只能綁一個流程,好幾張表單可以綁同一個。
  - 不能直接綁的流程會列在下方並寫原因(第幾關、什麼問題)。共用流程裡的角色只有名稱、沒有對到你組織的角色時,按「建客製流程」到流程管理以它為基底建一個自己的,選好角色、發布後再回來綁。
  - 改成「不走流程」前會先提醒:**已經進過審核的單(例如被退回修改的)再送出會被擋下**。
  - 清單上標「綁定的流程已失效」表示綁的流程已經不能用了,這張表單現在送不出去,請換一個流程或改成不走流程。

## 重要規則

- **刪除欄位只動草稿**:刪之前會列出哪些公式、條件、摘要或帶入規則還用到它;刪掉後那些地方會在「檢查結果」變成錯誤,要你自己改,系統不會自動幫你改。刪除分區時可以選「欄位移到未放置區」或「連同欄位一起刪除」。
- **已發布的版本不會變**:要改就開新草稿、再發布一版;已經填好的資料照它當時的版本顯示。
- **「草稿已被別人更新,請重新載入」**:有人同時在改同一份草稿,後存的人會被擋下。重新載入後再改。
- **受保護欄位**:欄位設成「受保護」或「限定可改」時,發布後會多出對應的權限,要在角色管理授予才看得到 / 改得動。
- 共用表單的建立與提供給各組織,由系統管理員處理;需要新的共用表單請聯絡系統管理員。
