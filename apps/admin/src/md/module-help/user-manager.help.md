# 使用者管理

## 這個模組做什麼

管理登入後台的帳號(使用者)。左側選組織即可篩選該組織(含下層)的使用者。

## 常用操作

- **新增/編輯**:管理員設定初始密碼,使用者首次登入時強制修改;選項欄位來自欄位管理。
- **所屬組織**:一位使用者可屬多個組織,勾選/取消勾選即加入/移除。加入會擴大他的資料可見範圍;移除時系統會列出受影響的角色,由你選擇保留或解除。保留的角色仍照常運作。
- **指派角色**:選擇組織後勾選角色;你只能指派自己也擁有的權限。
- **停用**:停用者無法登入。不提供刪除(保留歷程與授權紀錄)。

## 重要規則

- 清單與左側組織樹皆受你的可見範圍限制;範圍外的組織會顯示但不可選。
- 「所屬組織」欄的 +N 表示他還屬於其他組織,點開可見完整清單。
