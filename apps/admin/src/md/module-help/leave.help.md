# 請假

## 這個模組做什麼

用表單填寫請假單。要填哪些欄位由「表單」決定 —— 表單由系統管理員或你的管理員在「表單管理」設計好之後才會出現在這裡。表單綁了審核流程時,送出後會依流程一關一關審核,**審核通過才算完成**。

畫面共三頁:**清單**(這一頁)、**新增 / 編輯**、**詳情**。你送出的請假單也會出現在「申請中心」的「我的申請」。

## 常用操作

- **搜尋 / 篩選**:關鍵字比對每一筆的標題;可依「表單」與「狀態」篩選。
- **新增**:按「+ 新增」。可填的表單只有一張時直接進入填寫;有好幾張時先選一張。
- **存草稿 / 送出**:「存草稿」先存起來,草稿只有你自己看得到;「送出」後開始審核,狀態變成「審核中」。
- **看審核進度**:在詳情頁下方的「審核」區塊,看得到目前在哪一關、每一關由誰審、誰已經核准,以及完整的審核歷程。
- **撤回**:還沒有任何人審過之前,可以在詳情頁按「撤回」,改好再送。
- **被退回修改**:狀態變成「已退回」時,到編輯頁改好再送出,會從第一關重新審核。
- **作廢 / 複製為新單**:通過後的單不能再改。要更正就按「作廢」(要寫理由,不需要主管同意),再在詳情頁按「複製為新單」,改好重新送出。

## 狀態

| 狀態   | 意思                                               |
| ------ | -------------------------------------------------- |
| 草稿   | 存了還沒送                                         |
| 審核中 | 正在審;標「待處理」表示某一關暫時卡住,等管理員處理 |
| 已退回 | 審核者請你修改                                     |
| 已撤回 | 你自己收回                                         |
| 已完成 | 審核通過                                           |
| 已駁回 | 不通過,這張不能再改                                |
| 已作廢 | 通過後作廢了                                       |

## 重要規則

- **審核中的內容不能改**:要改請先撤回(還沒人審過時),或等退回後再改。
- **送出時被擋下**:畫面顯示「審核流程已移除」「審核流程尚未發布」或「審核流程設定有誤」時,請聯絡你的管理員。
- **看得到的按鈕就是你做得了的事**:通過後的單沒有「編輯」,只有「作廢」。
- 看得到哪些資料,由你的**可見範圍**與資料範圍規則決定;審核你的人只看得到他審的那一份內容。
