# 購物清單

## 這個模組做什麼

用表單填寫、保存購物清單。要填哪些欄位由「表單」決定 —— 表單由系統管理員或你的管理員在「表單管理」設計好之後才會出現在這裡,所以不同組織看到的欄位可能不一樣。

畫面共三頁:**清單**(這一頁)、**新增 / 編輯**、**詳情**。清單上每一列的操作會帶你到另外兩頁。

## 常用操作

- **搜尋**:輸入關鍵字比對每一筆的**標題**。
- **篩選**:可依「表單」與「狀態」(草稿 / 已完成)篩選,換條件會回到第一頁。
- **新增**:按「+ 新增」。現在可填的表單只有一張時直接進入填寫;有好幾張時先選一張。按鈕是灰的代表目前沒有可以填寫的表單。
- **帶入資料**:表單有設定帶入時,填寫頁上方會出現「帶入資料」。選一筆既有資料後,勾選要帶入的欄位(本欄已經有值的會提醒「會覆蓋」),按「帶入」。帶進來的值之後還可以自己改。
- **存草稿 / 送出**:「存草稿」先存起來下次再填,草稿只有你自己看得到;「送出」會一次完成存檔與送出,送出後就是「已完成」。
- **修改已完成的資料**:在編輯頁按「儲存修改」。每改一次都會留下一筆**修訂紀錄**。
- **詳情**:看這一筆的內容、附件(點檔名下載)與修訂紀錄;可切換檢視某一次修訂,或看它和前一次修訂差在哪裡。
- **刪除**:清單或詳情頁都可以刪,確認後才真的刪除,無法復原。

## 重要規則

- **看不到某個欄位是權限關係**:有些欄位要另外取得權限才看得到或才能修改;看得到但改不了的欄位會顯示為唯讀並附說明。
- **有些欄位會自己算**:計算欄位不用填,依其他欄位自動算出;需要的欄位還沒填時顯示「—」。有些欄位會依你填的內容才出現或變成唯讀。
- **「這筆資料已被別人更新,請重新載入」**:你在編輯的期間,這一筆被別人(或你在另一個分頁)改過了。按「重新載入」取得最新內容再改。
- **表單停用或改版不影響舊資料**:已經存在的資料照原本填寫時的表單內容顯示;表單不能再新增時,既有資料仍然看得到。
- **看得到的按鈕就是你做得了的事**:某一列沒有「編輯」或「刪除」,代表你對那一筆沒有該權限。
- 看得到哪些資料,由你的**可見範圍**與資料範圍規則決定。
