# 申請中心

## 這個模組做什麼

集中看**你送出的申請**與**等你審核的單**,不用一個一個模組去找。畫面有兩個分頁:

- **我的申請**:你填過、而且要經過審核的單(請假單等),不論在哪個模組。
- **待我審核**:派給你審核的單。

申請本身仍然留在各自的模組裡(例如請假單在「請假」);這裡只是把它們集中列出來。

## 常用操作

- **新申請**:按右上「新申請」,先選模組、再選表單,就會帶你到那個模組的填寫頁。這裡只列你能填、而且需要審核的表單。
- **看申請進度**:在「我的申請」找到那一筆按「檢視」。「目前關卡」欄顯示正在審的關卡;同時有好幾個部門在審時會列出好幾個。
- **改被退回的單**:狀態是「已退回」或「已撤回」的單,按「繼續編輯」回到填寫頁,改好再送出 —— 會從第一關重新審核。
- **審核**:在「待我審核」按「審核」,看完內容後在下方按「核准」「駁回」或「退回修改」。駁回和退回修改一定要寫理由,申請人會看到。
- **篩選**:兩個分頁都能依模組、表單篩選;「我的申請」還能依狀態篩選,「待我審核」可以切換「待處理 / 已處理」。

## 狀態怎麼看

| 狀態           | 意思                                          |
| -------------- | --------------------------------------------- |
| 草稿           | 存了還沒送                                    |
| 審核中         | 正在審                                        |
| 審核中(待處理) | 某一關暫時找不到可以審的人,正在等管理員處理   |
| 已退回         | 審核者請你修改;改好再送出                     |
| 已撤回         | 你自己收回了;可以改好再送出                   |
| 已完成         | 審核通過                                      |
| 已駁回         | 審核不通過,這張不能再改,需要的話請重新申請    |
| 已作廢         | 通過後你把它作廢了;可以「複製為新單」重新送出 |

## 重要規則

- **還沒有人審過之前可以撤回**:詳情頁下方的「撤回」只在沒有任何審核意見時出現。
- **通過後就不能改**:要更正請在詳情頁按「作廢」(要寫理由,不需要主管同意),再按「複製為新單」,改好重新送出審核。
- **「此關已結束」**:你按下核准 / 駁回時,這一關剛好已經由別人決定或任務已經換人,系統會重新載入最新狀態,你的動作不會生效。
- **審核者只看得到他審的那一份內容**:申請人之後修改再送出的新內容,只給新的審核者看。
- 看不到「審核」按鈕,代表這張單現在不是由你審。
