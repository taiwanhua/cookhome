# 欄位管理

## 這個模組做什麼

管理表單下拉選項的來源:欄位類別(如「性別」「單位」)與其下的欄位選項。各模組的表單會引用這裡的選項。

## 常用操作

- **檢視類別**:類別由種子資料定義,此頁唯讀。
- **新增/編輯選項**:在選定類別下維護選項(名稱、排序、啟用)。全域選項(種子資料)唯讀;你的組織可新增自訂選項,只有你的組織使用者看得到。
- **停用選項**:停用你的組織的自訂選項,既有資料不受影響,僅新填寫時不再出現。選項不提供刪除(避免舊資料失去對照)。

## 重要規則

- 標示「全域」的選項由系統統一維護、隨版本自動更新:你可以使用它,但不能編輯、也不能停用 — 需要停用某個全域選項請聯絡系統管理員。
- 需要新增類別時,請聯絡系統管理員。
