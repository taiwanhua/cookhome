# 欄位管理

## 這個模組做什麼

管理表單下拉選項的來源:欄位類別(如「性別」「示範分類」)與其下的選項。各模組的表單會引用這裡的選項。

畫面分兩邊:左邊是欄位類別,選一個類別,右邊就是它底下的選項表格。表格每一列的「來源」告訴你這個選項是哪來的 ——「全域」是系統統一提供、每個組織都有;「<你的組織名稱> 自訂」是你的組織自己加的。兩種混在同一份清單裡,因為填表的人看到的就是這一份。

## 常用操作

- **檢視類別**:類別由系統統一維護,這一頁唯讀。需要新增類別請聯絡系統管理員。
- **新增選項**:在選定的類別下新增你的組織的自訂選項,填顯示名稱、值、排序與描述。**值(value)是資料實際存下去的內容**,同一個類別裡不能和既有選項(包含全域選項)重複;重複時會標在「值」這一欄。
- **編輯選項**:改自訂選項的顯示名稱、排序與描述。**值建立後不能改** —— 既有資料以它對照,改掉舊資料就對不回來了;要換值請新增一個選項、把舊的停用。
- **停用 / 啟用選項**:切換該列的開關,立即生效,不需確認。停用只影響**新的填寫**,既有資料不受影響。選項不提供刪除(刪掉舊資料會失去對照)。

## 重要規則

- 標示「全域」的選項由系統管理員統一維護、隨版本自動更新:你可以使用它,但不能編輯,停用開關也是唯讀的 —— 那個開關一切下去是全平台生效,不是只有你的組織。需要停用某個全域選項請聯絡系統管理員。
- 你的組織自訂的選項**只有你的組織看得到**,其他組織(含上層與下層組織)看不到,也不會互相影響。
- 這一頁能做什麼由你的角色決定:沒有新增權限就看不到「新增自訂選項」,沒有停用權限就只看得到狀態、沒有開關。
