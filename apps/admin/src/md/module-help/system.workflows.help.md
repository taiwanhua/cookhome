# 流程管理

## 這個模組做什麼

設計表單送出後的**審核流程**:要經過哪幾關、每一關誰審、幾個人要過、什麼情況可以跳過。流程設計好、發布後,到「表單管理」把表單綁上流程,這張表單送出後就會開始審核。

畫面左側是流程清單,右側是選中流程的「流程設計」與「流程版本」兩個頁籤。流程分兩種:

- **共用流程**:由系統管理員提供給你的組織。你可以看,但不能直接改;要調整就「以此為基底建流程」。
- **自己的流程**:你自己建立,或以某個流程為基底建出來、只有你的組織看得到。

## 常用操作

- **建立流程**:按「建立流程」,填**流程 key** 與名稱。流程 key **建立後不能修改**(小寫英文開頭,只能用小寫英文、數字、底線)。
- **以此為基底建流程**:選一個基底版本,填新的 key 與名稱;建好後帶著一份草稿。共用流程裡的「角色」關卡只有一個名稱(例如「人資」),建好後要在那一關選你組織的角色,才能發布、綁定。
- **設計**:
  - 先在上方選**檢查用表單**:設計時用來對照的表單,列出可選的欄位、驗證審核者欄位與跳過條件。實際送出時以綁定的表單為準,綁定時會再驗一次。檢查用表單會跟著草稿一起存。
  - 點流程圖上的關卡,在右側設定名稱、**審核者**、**會簽**、**允許退回修改**與**跳過條件**。
  - 審核者有四種:**指定使用者**、**角色**(持有這個角色的人)、**表單欄位**(送出時表單裡選的那個人;從檢查用表單的使用者欄位挑,沒選檢查用表單時會提示「請先選檢查用表單」)、**主管**(從申請所屬的組織往上找,第 1 層是最近的一組主管;主管在「組織管理」設定)。
  - 會簽:「任一人核准即過」或「全部核准才過」;不論哪一種,只要有人駁回就駁回。
  - 跳過條件:例如「天數 ≤ 1」就跳過人資關。欄位來自檢查用表單,沒選時欄位下拉會提示「請先選檢查用表單」。
  - 「在後面加一關」加在這一關之後;「從此關分流」讓這一關通過後同時交給好幾條分支(例如財務、法務、採購)審,**全部分支都通過**才會在匯合點會合,之後可以結束或再接一關。分支裡可以再加關卡,但不能再分流。
  - 拖曳關卡可以調整順序或移到別條分支;也可以用屬性面板的「上移 / 下移 / 移到分支」。刪除一關時前後會自動接上;刪掉分支唯一的一關就是刪掉那條分支。
  - 「檢查結果」隨時列出錯誤與警告,點一下會選中出問題的那一關。有錯誤不能發布,警告可以。
  - 按檢查用表單旁的**檢查**做一次完整檢查(包含指定的人是否還在、表單欄位是否存在),結果依關卡列出,點一筆會選中那一關並打開右側設定。沒選檢查用表單時,欄位類的檢查不會做,流程結構照樣檢查。
  - 改完按「存草稿」。
- **版本**:草稿那一列按「發布」,填變更說明;「退役目前版本」後,綁這個流程的表單會暫時送不出去,直到再發布新版。
  - **檢視 vN**:以唯讀方式打開已發布或已退役的版本,可以點關卡看設定、按「檢查」看結果,但不能修改或存。還沒有草稿時,旁邊可以「以 vN 為基底開新草稿」。檢視時,草稿的設計不會不見,按「關閉檢視」就回到草稿。
  - **刪除草稿**:不要這份草稿了就刪掉(會先請你確認;設計器裡還沒存的改動也會一起丟掉)。已發布的版本不受影響,之後可以再開新草稿。
- **阻擋清單**:頁首的「阻擋清單」列出卡住的單(見下方)。

## 阻擋清單

- **阻擋**:某一關找不到可以審的人(例如角色裡沒有人、主管沒設),或審核者被停用、離開組織,這張單就停在那裡等你處理,系統**不會自動換人或跳過**。
  - **改派**:把卡住的任務交給另一個人。
  - **新增審核者**:那一關完全找不到人時,指定一位。
  - 申請人自己、以及已經在這一關的人不能選。
- **需要推進**:處理過程中斷過、還有步驟沒完成的單。按「重試推進」讓系統接著做完,重按幾次結果都一樣。

## 重要規則

- **進行中的審核不受改版影響**:已經送出的單照它送出時的流程版本走完;改版、退役只影響之後送出的單。
- **已發布過的關卡 key 不能改**。
- **「草稿已被別人更新,請重新載入」**:有人同時在改同一份草稿,後存的人會被擋下。
- **有未存的變更時換流程**,會先問你要留下、放棄還是先存草稿;發布時如果還有沒存的變更,發布的是上次存的草稿。
- 共用流程的建立與提供給各組織,由系統管理員處理。
