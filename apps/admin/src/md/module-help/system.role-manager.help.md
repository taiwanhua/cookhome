# 角色管理

## 這個模組做什麼

角色是一組權限的集合,由單一組織擁有並自行管理;把角色授予使用者,他就取得對應的功能。

## 常用操作

- **建立/編輯角色**:選擇所屬組織、名稱與描述。
- **權限設定**:逐項勾選,或勾「全部(*)」— 涵蓋**該模組自己這一層**現有及未來新增的權限;下層模組要另外勾它們自己的「全部(*)」,或用模組列旁的「全選整組」一次勾完整棵。
- **分配使用者**:僅能選擇此角色所屬組織**或其下層組織**的使用者;人不在清單裡時,請先到使用者管理將他加入組織。

## 重要規則

- 你只能下放**自己擁有**的權限;下放後即使你失去該權限,已授出的不會自動收回。
- 授予角色**不會**改變使用者的所屬組織。
- 系統內建角色不可刪改。
