# 組織管理

## 這個模組做什麼

管理組織樹:在你的組織之下建立部門或分店,形成層級。組織是資料隔離的邊界 — 使用者看得到哪些資料,取決於他屬於哪些組織。

畫面分兩邊:左邊是組織樹,選一個組織,右邊就顯示它的內容與可以對它做的動作。右邊有兩個分頁:「組織資料」(上層組織、描述、商標、擁有者)與「成員」(直接屬於這個組織的人)。分頁與動作按鈕都只在你有該項權限時才會出現。

## 常用操作

- **新增子組織**:在選定的組織下建立部門/分店,只需名稱與描述。
- **編輯**:改名稱、描述與商標;要把組織搬到別的上層時,在編輯視窗選擇新的上層組織 — 可以搬到你管理範圍內的任何組織底下,除了它自己和它底下的組織。
- **商標**:編輯視窗一打開就看得到目前的商標;選一張新的圖(PNG / JPG / WebP,建議正方形,2MB 以內)可以取代它,按「移除」則是把商標拿掉;不動這一欄就不會改到商標。儲存後生效。
- **主管**:在編輯視窗的「主管」欄可以為組織設一位或多位主管,從同一個組織底下(含各部門、分店)啟用中的使用者挑選;主管不必是這個組織的成員。審核流程裡「主管」那一關會從申請所屬的組織往上,找到第一個設了主管的組織,由那裡的主管審核。右邊「組織資料」會列出目前的主管,已停用的會另外標註。
- **停用**:此組織與其**全部下層組織**會一併停用;僅屬於停用組織的使用者將無法登入。重新啟用時**只會啟用這一個組織**,下層要各自再啟用。停用中的組織在組織樹上會標示「停用」。
- **成員**:「成員」分頁列出**直接屬於這個組織**的人,包含姓名、帳號、狀態,以及他還屬於哪些其他組織。下層組織的成員不會出現在這裡 — 那些人要到使用者管理查看。
- **加入成員**:在「成員」分頁按「加入成員」,從清單中勾選一位或多位使用者,一次把他們加進這個組織。清單只會列出**你管得到、而且還不屬於這個組織**的人;找不到某個人時,請先到使用者管理確認他存在、而且在你的管理範圍內。加入不會影響他原本的組織與角色。
- **把人移出組織**:不在這一頁。請到使用者管理找到那個人,用「選擇所屬組織」調整 — 移出可能會讓他失去某些角色的資格,那裡會先列出受影響的項目讓你選擇怎麼處理。
- **刪除**:四個條件全部成立才可以刪 — 沒有下層組織、沒有成員、沒有以它為擁有組織的角色、沒有其他資料掛在它底下;任何一項不成立都會**逐條列出原因**,請改用停用。刪除後資料仍保留,只是不再出現在組織樹上。

## 重要規則

- 頂層組織不可停用、不可搬移、不可刪除 — 這幾個按鈕會是灰的,滑過去會說明原因;需要這些變更請聯絡系統管理員。
- 「使用者可見下層組織資料」開關只出現在**頂層組織**的編輯視窗,設定套用整個組織:開啟時,每位使用者可見自己所屬組織與其下層的資料;關閉時僅見所屬組織。
- 「擁有者」欄位只出現在**頂層組織**的資料區:被指定的人不會被解除管理員授予、不會被移出組織、也不會被停用。要更換擁有者請聯絡系統管理員。
- 你能看到的組織範圍由你持有的角色決定:每個角色都標了它所屬的組織,你可以管理那個組織與它底下的所有組織;範圍外的組織不會出現在組織樹上。持有多個角色時,組織樹可能有多個起點。
- 「使用者可見下層組織資料」開關只影響大家看得到多少**業務資料**,不影響這一頁 — 開關關著時,你照樣管得到範圍內的每一個組織。
