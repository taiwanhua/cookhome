# 組織管理

## 這個模組做什麼

管理組織樹:在你的組織之下建立部門或分店,形成層級。組織是資料隔離的邊界 — 使用者看得到哪些資料,取決於他屬於哪些組織。

## 常用操作

- **新增子組織**:在選定的組織下建立部門/分店,只需名稱與描述。
- **編輯**:改名稱、描述與商標;要把組織搬到別的上層時,在編輯視窗選擇新的上層組織 — 新的上層必須在**同一個頂層組織**之下,而且不能是這個組織自己的下層。
- **停用**:此組織與其**全部下層組織**會一併停用;僅屬於停用組織的使用者將無法登入。重新啟用時**只會啟用這一個組織**,下層要各自再啟用。
- **刪除**:四個條件全部成立才可以刪 — 沒有下層組織、沒有成員、沒有以它為擁有組織的角色、沒有其他資料掛在它底下;任何一項不成立都會列出原因,請改用停用。刪除後資料仍保留,只是不再出現在組織樹上。

## 重要規則

- 「使用者可見下層組織資料」開關只出現在**頂層組織**的編輯視窗,設定套用整個組織:開啟時,每位使用者可見自己所屬組織與其下層的資料;關閉時僅見所屬組織。
- 組織樹會顯示整個組織的結構,但你看得到資料的組織之外的節點是**灰的**:能看見名稱與層級關係,不能選取、也不能對它做任何操作。
