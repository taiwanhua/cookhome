# 示範模組2

## 這個模組做什麼

系統內建的第二個示範模組,操作與示範模組1 相同(建立、編輯、刪除示範項目),但**沒有資料範圍設定** — 用來對照:沒有設定資料範圍的模組,看得到的資料由你的可見範圍決定。

畫面共三頁:**清單**(這一頁)、**檢視**、**新增 / 編輯**。清單上每一列的操作會帶你到另外兩頁,改完會回到清單。

## 常用操作

- **搜尋**:輸入關鍵字比對**名稱與備註**。
- **新增 / 編輯**:只要填名稱(必填)與備註。名稱空白時會直接標在該欄位上。
- **刪除**:清單或檢視頁都可以刪,確認後才真的刪除,無法復原。

## 重要規則

- **這一頁刻意比示範模組1 少**:沒有分類、沒有狀態、沒有內部備註、沒有封面與附件、沒有變更歷程。要看那些功能請改用示範模組1。
- **看得到的按鈕就是你做得了的事**:某一列沒有「編輯」或「刪除」,代表你對那一筆沒有該權限,或是還沒被授權進入那一頁。
- 離開還沒儲存的表單時會先問一次;直接關掉分頁則由瀏覽器提醒。
- 看得到哪些示範項目,由你的**可見範圍**決定;資料範圍規則不會影響這個模組 — 這正是它拿來對照的地方。
- 不需要此模組時,可請系統管理員停用整個示範群組。
