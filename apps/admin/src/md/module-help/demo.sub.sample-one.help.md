# 示範模組1

## 這個模組做什麼

系統內建的示範模組,用來測試權限設定與熟悉操作,不影響正式資料。你可以在這裡練習:建立、編輯、刪除示範項目,並觀察不同角色與資料範圍設定下看到的內容差異。

## 常用操作

- **新增/編輯**:填寫名稱、分類(選項來自欄位管理)、備註,可上傳封面圖與附件。
- **內部備註**:此欄位需要另外的權限才看得到、改得動 — 適合用來測試欄位層級的權限。
- **變更歷程**:編輯頁的歷程區塊需要對應權限才會顯示。
- **刪除**:列表上操作,確認後刪除。

## 重要規則

- 每筆示範項目都有**狀態**(草稿 / 已發布 / 已封存,新建時是「草稿」);它是可以拿來設定資料範圍規則的固定選項欄位。
- 看得到哪些示範項目,可能受系統管理員設定的資料範圍規則影響 — 適合用來驗證這類設定。
- 不需要此模組時,可請系統管理員停用整個示範群組。
