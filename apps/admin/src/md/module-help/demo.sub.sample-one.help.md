# 示範模組1

## 這個模組做什麼

系統內建的示範模組,用來測試權限設定與熟悉操作,不影響正式資料。你可以在這裡練習:建立、編輯、刪除示範項目,並觀察不同角色與資料範圍設定下看到的內容差異。

畫面共三頁:**清單**(這一頁)、**檢視**、**新增 / 編輯**。清單上每一列的操作會帶你到另外兩頁,改完會回到清單。

## 常用操作

- **搜尋**:輸入關鍵字比對**名稱與備註**(不會比對內部備註)。
- **依分類篩選**:選項來自「欄位管理」的「示範分類」;已停用的選項不會出現在這裡,但既有資料仍照樣顯示它原本的分類名稱。
- **新增 / 編輯**:填寫名稱(必填)、分類、狀態、備註,可上傳封面圖與附件。名稱空白或分類不在可用選項內時,會直接標在該欄位上。
- **內部備註**:此欄位需要另外的權限才看得到、改得動 — 適合用來測試欄位層級的權限。看得到但改不動時,欄位會是唯讀的。
- **封面與附件**:封面是公開的圖片,拿到網址的人都看得到,所以請不要放機密內容,只收 PNG / JPG / WebP、單檔 2MB 以內;附件是私有檔案,按下「下載」時系統才核發一條短效連結,收圖片與 PDF / Word / Excel / ZIP、單檔 20MB 以內。
- **填寫提示**:新增頁的提示區塊需要對應權限才會顯示;沒有它不影響新增。
- **變更歷程**:編輯頁的歷程區塊需要對應權限才會顯示;沒有它不影響編輯與儲存。內部備註的內容不會出現在歷程裡。
- **刪除**:清單或檢視頁都可以刪,確認後才真的刪除,封面與附件一併移除,無法復原。

## 重要規則

- 每筆示範項目都有**狀態**(草稿 / 已發布 / 已封存,新建時是「草稿」);它是可以拿來設定資料範圍規則的固定選項欄位。另外還有**啟用 / 停用**,那是不同的另一個欄位,目前只在清單與檢視頁以標籤顯示,畫面上沒有切換的入口(示範資料裡本來就有一筆是停用的)。停用的項目**照樣列出來**,只是標示為停用。
- **建立者**顯示「—」是正常的:系統一開始就準備好的示範項目沒有對應的使用者。自己新增的項目就會顯示你的名字。
- **看得到的按鈕就是你做得了的事**:某一列沒有「編輯」或「刪除」,代表你對那一筆沒有該權限,或是還沒被授權進入那一頁。
- **沒有「欄位管理」的檢視權限時**,分類的選項清單拿不到:清單上的分類篩選不會出現,編輯時分類欄位會變成唯讀(原本的分類仍然保留)。
- 離開還沒儲存的表單時會先問一次;直接關掉分頁則由瀏覽器提醒。
- 看得到哪些示範項目,可能受系統管理員設定的資料範圍規則影響 — 適合用來驗證這類設定。
- 不需要此模組時,可請系統管理員停用整個示範群組。
