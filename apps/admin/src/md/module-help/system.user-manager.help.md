# 使用者管理

## 這個模組做什麼

管理登入後台的帳號(使用者)。左側選組織即可篩選該組織(含下層)的使用者;右上的搜尋框可用姓名或 Email 再縮小範圍,清單下方是分頁。

## 常用操作

- **新增**:填姓名、帳號、Email 與所屬組織(預設帶入左側選中的組織),並選一種啟用方式 —
  - **寄啟用信**(預設):不設密碼,系統寄一封 7 天內有效的信,由本人在信裡的連結設定自己的密碼。
  - **直接設定初始密碼**:你輸入一組初始密碼交給他,他首次登入時必須改掉。
- **編輯**:改姓名、暱稱、性別、電話、地址、Email、帳號;所屬組織與角色各有專用視窗,不在這裡改。
- **所屬組織**:一位使用者可屬多個組織,在樹上勾選/取消勾選即加入/移除。加入會擴大他的資料可見範圍;**有移除時**會再跳一個確認視窗,列出這次移除會讓哪些角色失去資格、各是什麼原因,你可以三選一:全部保留、只解除該組織的角色、解除所有失去資格的角色(預設)。保留的角色仍照常運作。
- **指派角色**:清單列出你自己擁有的角色,每個角色旁標示它所屬的組織,上方可依組織篩選;勾選即指派、取消即解除。你沒有的角色會是灰的(不能指派給別人),對方已有、而你沒有的角色也只能看不能動。
- **停用**:停用者無法登入,而且當下就會被踢出所有已登入的裝置。不提供刪除(保留歷程與授權紀錄)。

## 重要規則

- 清單與左側組織樹皆受你的可見範圍限制;範圍外的組織會顯示但不可選。
- 「所屬組織」欄的 +N 表示他還屬於其他組織,點開可見完整清單。
- 角色欄的「組織外」表示:使用者不在該角色的所屬組織內。權限照常有效,只是他看得到的資料仍以自己的所屬組織為準。
- 每位使用者至少要保留一個所屬組織,最後一個不能移除。
- 頂層組織的擁有者受保護:不能被停用、不能被移出頂層組織,其管理員角色也不能被解除。需要變更請聯絡系統管理員。
- 身分證字號屬於高度敏感資料:沒有對應權限的人看不到,也不能修改。
- 每一次新增、編輯、停用、所屬組織與角色的變更都會留下紀錄。
- 看不到組織樹時(你沒有組織管理的檢視權限),清單會直接列出你看得到的所有使用者,「所屬組織」的調整則要請有權限的人協助。
