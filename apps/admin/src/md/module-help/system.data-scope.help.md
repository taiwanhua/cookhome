# 資料範圍

## 這個模組做什麼

設定各模組資料的查詢範圍規則:誰在查資料時,只能看到符合條件的部分。左側選資料目標(一列一個模組),右側編輯規則。

## 規則怎麼運作

- 一條規則 = **套用對象**(全部人/指定角色/指定組織/指定使用者)+ **過濾條件**。
- 條件可用 AND(全部成立才放行)/ OR(其中一個成立即可)組合,並可建立巢狀群組 — 整個群組視為上一層的一個條件。
- 多條規則命中同一個人時,由頂層「規則合成」決定:**OR = 滿足任一規則即可,看得到的變多;AND = 每條規則都要滿足,看得到的變少**。合成只算**命中他的那幾條** — 只被一條規則命中的人,無論設成哪一種都只受那一條限制。
- 沒有命中任何規則的人 → 預設:可見範圍內。
- **租戶隔離保底永遠生效**:規則只能把可見範圍切小,不可能讓人看到可見範圍外的資料。

## 畫面怎麼操作

- 左邊是資料目標清單,**一列一個模組**:主文字是模組名稱、下面一行是資料所在的 collection。幾個模組可能共用同一個 collection(例如表單模組都存在 `form_submissions`),它們各自一列、各自一份規則,互不影響。目前**有規則**的會標「已設規則」;把一個目標的規則全部刪掉再儲存,這個標記就會消失。點一個目標,右邊就是它的規則。
- 「規則合成」決定多條規則命中同一個人時怎麼合;「+ 新增規則」加一條規則。
- 每條規則先選**套用對象**:選「角色」或「使用者」時,對象欄位**直接輸入就會即時篩出候選**(角色可用名稱或所屬組織找),選中的會變成一個個小標籤,點標籤上的「×」就能移掉;選「組織」是組織樹多選,選「全部」則不必再挑對象。
- 條件列由左到右是**欄位 → 條件 → 值**:選了欄位才知道可以用哪些比較方式與值,所以**換欄位時條件與值會一起重設**。
- 「+ 條件」加一列條件,「+ 群組」加一個括號;群組裡還可以再加一層,畫面上最多三層。
- 改完按「儲存」;「放棄變更」把這個目標的規則還原成上次儲存的樣子。沒儲存就去點別的資料目標時會先問你要不要放棄。
- 送出前畫面會先檢查明顯的問題(沒填值、空群組、沒挑套用對象),錯誤會標在出問題的那一列。

## 常用寫法

- 「某角色只看自己建立的」:套用對象=該角色,條件「建立者 屬於 【操作者本人】」。
- 「某租戶只看某日期後的」:套用對象=該租戶頂層組織,條件「建立時間 之後 某日期」。

## 重要規則

- 資料目標與可篩欄位由各模組的種子宣告;要新增請走開發流程。
- 每個資料目標都一定有這幾個共通欄位可篩:組織、建立者、更新者、建立時間、更新時間、刪除時間。
- 欄位的型別決定可用的比較方式:組織 / 使用者是「屬於」「不屬於」(可選【操作者本人】【操作者的所屬組織】);日期是「之間」「之前」「之後」;選項欄位是「屬於」「不屬於」。
- 規則管的是「看得到哪些」,同時也管得到「改得到 / 刪得到哪些」 —— 看不到的資料,那個人也改不到、刪不到。
- 「指定角色」比對的是對方**啟用中**的角色:角色一停用,以它命中的規則立刻不再套在那個人身上。
- 動態值算不出對象時(例如那個人沒有任何所屬組織),該條件**一筆都不放行**,不會退回成「沒有這條規則」。
- 儲存是整份覆蓋:畫面上留著的就是之後生效的全部;全部刪光再儲存,等於這個目標沒有規則。
- 本頁僅根組織可用。
