# 資料範圍

## 這個模組做什麼

設定各資料目標(collection)的查詢範圍規則:誰在查資料時,只能看到符合條件的部分。左側選資料目標,右側編輯規則。

## 規則怎麼運作

- 一條規則 = **套用對象**(全部人/指定角色/指定組織/指定使用者)+ **過濾條件**。
- 條件可用 AND(全部成立才放行)/ OR(其中一個成立即可)組合,並可建立巢狀群組 — 整個群組視為上一層的一個條件。
- 多條規則命中同一個人時,由頂層「規則合成」決定:**OR = 滿足任一規則即可,看得到的變多;AND = 每條規則都要滿足,看得到的變少**。
- 沒有命中任何規則的人 → 預設:可見範圍內。
- **租戶隔離保底永遠生效**:規則只能把可見範圍切小,不可能讓人看到可見範圍外的資料。

## 常用寫法

- 「某角色只看自己建立的」:套用對象=該角色,條件「建立者 等於 【操作者本人】」。
- 「某租戶只看某日期後的」:套用對象=該租戶頂層組織,條件「建立時間 之後 某日期」。

## 重要規則

- 資料目標與可篩欄位由各模組的種子宣告;要新增請走開發流程。
- 每個資料目標都一定有這幾個共通欄位可篩:組織、建立者、更新者、建立時間、更新時間、刪除時間。
- 欄位的型別決定可用的比較方式:組織 / 使用者是「屬於」「不屬於」(可選【操作者本人】【操作者的所屬組織】);日期是「之間」「之前」「之後」;選項欄位是「屬於」「不屬於」。
- 儲存是整份覆蓋:畫面上留著的就是之後生效的全部;全部刪光再儲存,等於這個目標沒有規則。
- 本頁僅根組織可用。
