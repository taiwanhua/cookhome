# 模組與權限

## 這個模組做什麼

檢視系統的模組樹(側欄結構、選單)與每個模組的權限清單。僅系統管理員可見。

## 常用操作

- **啟用/停用模組**:停用父模組時,其下層模組一併停用;**重新啟用只會啟用該模組本身**,下層需逐一開啟。
- **啟用/停用權限**:右側權限清單的每一筆也能切換。停用後**所有角色都不再持有該權限**(即使角色的權限矩陣仍勾著),按鈕與對應的 API 一併失效。

## 重要規則

- 模組與權限屬於**種子資料**,隨系統版本自動更新 — 除了啟用/停用開關,此頁其餘內容皆為唯讀。
- 需要新增模組或調整選單結構時,請聯絡系統管理員。
- 資料範圍不在此頁,由「資料範圍」頁設定(僅系統管理員)。
