# project-bootstrap

操作正本是 `docs/agents/project-bootstrap.md`。本 skill 只指路,步驟、指令與規則都在正本,不在這裡重寫;兩者不一致時以正本為準並回報差異。

1. 先讀 `CLAUDE.md`,再讀正本全文與它指到的初始化索引、品牌註冊表、環境變數登記、deployment。
2. 依正本的節次執行:開始前的核對 → 收集輸入 → 取得底座版本並建立 repo → 寫入專案值 → 外部資源 → 驗證 → 回報。接續既有初始化時先走正本「重跑」。
3. 已有答案的輸入直接沿用,只問缺項;外部操作依使用者已授權的範圍執行。
4. 進度與三種狀態(已提供 / 已建立 / 已驗證)記在本次初始化的 issue / PR,格式依 `docs/agents/issue-tracker.md`。

拿不到底座正式 tag、或採用的底座版本缺少正本提到的機制時,停下回報,不以替代做法完成。
