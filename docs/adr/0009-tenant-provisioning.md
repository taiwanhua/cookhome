# 租戶開通:自動四步 + 角色模板複製;「模組與權限」root 專屬

root 在組織管理執行「開通租戶」(輸入租戶名稱 + 首任管理員 email)時,系統自動:①建立租戶 Org(根組織直接子組織)②從種子角色模板複製一份「租戶管理員」角色到該租戶名下 — 各租戶各持一份、可自行客製、互不影響 ③模板權限 = 全部模組 wildcard **扣除 root 專屬模組**(至少含「模組與權限」— 系統結構不開放租戶)④以 email 建立首任租戶管理員並完成 org_user 與 user_role 綁定。組織/使用者/角色/欄位管理為租戶可用模組。

「新增子組織」是另一個較輕的入口(名稱+描述),供租戶內建立部門/分店,不觸發上述流程。組織停用連動整棵子樹(僅屬停用樹的使用者無法登入);有子孫或關聯資料的組織禁止刪除,只能停用;搬移限租戶內(ancestors 批次重建),跨租戶禁止。

未來按租戶差異化可用模組時,以 `org_module` 關聯表達(核心關聯 enum 擴充),模板生成時改讀該關聯。
