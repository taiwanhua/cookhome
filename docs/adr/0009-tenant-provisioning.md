# 租戶開通:自動四步 + 角色模板複製;「模組與權限」根組織專屬

根組織的操作者(需持「開通租戶」權限)在組織管理執行開通(輸入租戶名稱、首任管理員 Email、商標選填)時,系統自動:

1. 建立租戶 Org(根組織的直接子組織)
2. 從種子模板複製一份「租戶管理員」角色到該租戶名下 — 各租戶各持一份、可自行客製、互不影響
3. 模板權限 = 全部模組 wildcard **扣除根組織專屬模組**(至少含「模組與權限」)
4. 以 Email 建立首任管理員並完成 org_user、user_role 綁定 — **不設初始密碼**:寄「啟用帳號」信,由其在「設定新密碼」頁自行設定。根組織端不經手租戶密碼(初始密碼+首登強改僅用於同組織內手動新增使用者)

**Token 效期**:啟用連結 7 天、重設密碼連結 30 分鐘;單次使用、存雜湊(`action_tokens`,TTL index),效期以環境變數可調。啟用逾期走「忘記密碼」流程自助取得新連結,毋須根組織重寄。

**其他規則**:

- 「新增子組織」是另一個輕量入口(名稱+描述),不觸發上述流程。
- 組織停用連動整棵子樹;有子孫或關聯資料者禁止刪除,只能停用;搬移限租戶內,跨租戶禁止。
- 未來按租戶差異化可用模組時,以 `org_module` 關聯表達,模板生成改讀該關聯。
