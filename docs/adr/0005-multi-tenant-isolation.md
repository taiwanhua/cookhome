# 多租戶隔離:orgId + 中央強制過濾 + ancestors 樹

所有租戶資料 collection 掛 `orgId`,由中央機制(Mongoose plugin 從 JWT 的當前組織自動注入查詢條件)強制過濾,不依賴各 handler 自律;複合索引以 orgId 開頭。組織與模組樹採物化路徑:每份文件存 `ancestors` 祖先 id 陣列,子樹查詢一句 `find({ ancestors: X })` 完成,搬移節點時批次更新子孫。

父組織可見性是**租戶頂層**(根組織的直接子組織)的開關,存於其 `settings`、套用整棵子樹 — 不做逐層自決(嵌套矛盾難解)。根組織(平台運營者)預設可見全部。front 會員註冊預設歸屬根組織,底座允許指定其他組織。

欄位管理:類別(母檔)為全域種子、租戶不可自訂;選項(子檔)帶可空 `orgId` — null 為全域種子選項、有值為租戶自訂,下拉載入時合併(`$or`),選項含 `order` 與啟用狀態(下架不刪,舊資料仍引用)。
