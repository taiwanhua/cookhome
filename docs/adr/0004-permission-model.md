# 權限模型:模組樹為命名空間、wildcard 含子孫、純加法、防越權下放

模組樹(= 側欄/頁面劃分,含隱藏頁)是權限的命名空間。權限 key 全 kebab-case、點分層(`content-manager.recipe.edit.show-field-a`),與顯示名分離;細至欄位顯示皆可為一筆權限。每個模組下有一筆 `模組key.*` 萬用字元權限:角色綁定後,該模組**及其全部子孫模組**的權限(含未來新增)視為擁有。解析規則:聯集、純加法、沒有 deny。

API 權限預設**重用頁面權限 key**(controller 標註),避免頁面/端點雙重記帳;僅無對應頁面的純 API 能力放進隱藏的 `api` 模組樹。

防越權下放:操作者(編輯角色或指派角色時)只能授出自身有效權限集的子集,wildcard 以 prefix 判定;日後操作者失去權限,已授出的不自動回收。授權相關動作寫入 `audit_logs`(誰、何時、動作、對象、前後值)— v1 只記授權變更,不記一般 CRUD。
