# 資料範圍:規則產生器 + BaseRepository 統一執行

## 定位

資料範圍與權限體系**分離**:權限管「進哪些頁、頁裡什麼能用」(ADR-0004/0011),資料範圍管「查資料時看得到哪些」。因此 wildcard(`模組key.*`)只涵蓋功能權限,永遠不影響資料範圍。

## 機制

- 每個「資料目標」(collection)一份規則設定;**沒有規則命中操作者 → 預設 = 可見範圍內**(等於沒設定)。
- 一條規則 = **套用對象**(全部人 / 指定角色 / 指定組織 / 指定使用者)+ **過濾條件**(巢狀 AND/OR 樹,任意深,UI 建議 3 層)。
- **頂層合成(combineOp)可切換**:多條規則命中同一操作者時 — OR(預設)= 各規則允許的範圍**聯集**,命中越多看得到越多;AND = **交集**,每條規則都要滿足,命中越多看得到越少。
- 租戶差異化:套用對象選「指定組織」指向租戶頂層即可,不需額外表。
- 執行:BaseRepository 查詢該 collection 時 → 找套用對象命中操作者的規則 → 依頂層合成組條件 → **最外層永遠 AND 租戶隔離保底(orgId ∈ 可見範圍),不可關閉**。
- 設定整包記憶體快取,儲存時作廢。

**執行面的邊界(2026-09-20 / #205 定案;逐條語意的正本在 `docs/modules/data-scope.md`「執行面的回傳語意」,本 ADR 只指路)**:

- 規則套在**整組查詢中介層**(與租戶保底同一組),**含寫入與刪除** — 看不到的資料也改不到、刪不到,不是只限讀取。
- **AND 合成 = 命中規則之間的交集**;只命中一條的人**只受那一條限制**(沒命中的規則不會把他一起關進去)。
- 執行需要的操作者事實是 `memberOrgIds`(`org_user` 直接關聯)與 `roleIds`(啟用中角色),與 `visibleOrgIds` / `managedOrgIds` 是**四個不同的集合**(ADR-0005「管理範圍與可見範圍的分工」的表)。本 ADR 說的「所屬組織」一律指 `memberOrgIds`。
- **`rules: []` 與「從來沒設定過」不同**:前者是整份覆蓋成空(文件仍在、執行面等同沒有規則),後者 `dataScopeRule` 回 `null`。
- 動態值算不出對象時(沒有所屬組織等)**fail-closed**:該條件命中不到任何資料,不是當作沒這條規則。

## 欄位目錄(seed 宣告)

- 各資料目標在模組 seed 宣告 `dataScopeTarget`:collection、中文名、描述、可篩欄位清單(欄位名/中文名/型別/enum 選項);seed 落庫至 `data_scope_targets`(種子資料,「資料範圍」頁左側清單的來源)。
- **基礎欄位由底座自動掛進目錄**:組織(orgId)、建立者(createdBy)、更新者(updatedBy)、建立/更新/刪除時間。
- **型別決定 UI 與查詢翻譯**,翻譯器不認識個別欄位:

| 型別 | 運算子             | 值來源(範圍欄的 UI 與代入)                  |
| ---- | ------------------ | ------------------------------------------- |
| org  | in / not in        | 可見組織選擇器,或動態值【操作者的所屬組織】 |
| user | in / not in        | 可見使用者選擇器,或動態值【操作者本人】     |
| date | 之間 / 之前 / 之後 | 日期選擇器(區間為兩個)                      |
| enum | in / not in        | seed 宣告的固定選項                         |

- **動態值存佔位符**,查詢當下代入正在查的人的 userId / 所屬組織。「僅本人」=「建立者 = 【操作者本人】」;「僅所屬組織」=「組織 = 【操作者的所屬組織】」。

## 儲存(`data_scope_rules`)

```jsonc
{
  "collection": "demo_items_one", // unique
  "combineOp": "OR", // 頂層合成
  "rules": [
    {
      "audience": { "type": "role", "ids": ["客服角色id"] },
      "filter": {
        "op": "AND",
        "children": [
          {
            "field": "createdBy",
            "cond": "in",
            "value": { "kind": "dynamic", "ref": "current-user" },
          },
        ],
      },
    },
  ],
}
```

## UI(「資料範圍」頁)

系統管理群組下、**根組織專屬**。左 = 資料目標清單(seed);右 = 說明 + 預設提示 + 規則編輯器(套用對象 + 條件樹,目錄驅動:選欄位 → 依型別出運算子 → 依值來源出選擇器)。

## 預留不實作

**單筆分享**:把一筆資料分享給範圍外的特定人(如 Google 文件的「共用給某人」)。屆時需要:模組宣告支援分享、一張「誰把哪筆分享給誰」的關聯、查詢時在範圍條件外多一個 OR「或這筆有分享給我」。有真實需求再建。
