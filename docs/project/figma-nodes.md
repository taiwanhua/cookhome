# CookHome 設計稿節點

底座模組在本專案設計檔裡的畫面節點。底座文件(`docs/modules/*.md`、FIGMA-09)只登記底座 Design System 的節點,本專案的節點寫在這裡;設計檔身分見[品牌值](branding.md#設計資源)。

現行後台畫面在 [CookHome Screens](https://www.figma.com/design/Wi9DIhrSILy2bj9nqXb051),取自 Screens Starter;下面兩節是保留的 [CookHome Design System](https://www.figma.com/design/SvnBvi8Opfj8daJAclOnWW) 舊檔節點,不適用於 Screens,兩檔節點 id 不可混用。
